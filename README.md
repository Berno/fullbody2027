# Full Body Tracker V7 - GitHub Pages / Android PWA

Carica nella root del repository: index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png.

GitHub: Settings -> Pages -> Build and deployment -> Deploy from a branch -> main -> / (root).

Su Android/Chrome apri l’URL GitHub Pages e usa “Aggiungi a schermata Home” / “Installa app”.

I dati restano nel Local Storage dello stesso origin. Usa periodicamente Backup JSON.
